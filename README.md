# 라움스톡 (Raumstock)

아이와 함께 실제 과거 시장 데이터로 투자를 게임처럼 배우는 앱 — 컨셉 프로토타입 단계

- 컨셉: [docs/CONCEPT.md](docs/CONCEPT.md)
- 전체 기획서: [docs/PLANNING.md](docs/PLANNING.md)
- 프로토타입: `prototype/` — `cd prototype && python3 -m http.server` 후 http://localhost:8000
- 데이터: `data/raw/` (출처는 [data/SOURCES.md](data/SOURCES.md)), `node scripts/build-data.mjs`로 `prototype/data.js` 생성
