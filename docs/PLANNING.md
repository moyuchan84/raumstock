# 라움스톡 (Raumstock) 기획서 v0.1

> **업데이트 (v0.2):** 주 대상은 초등학생, 실제 데이터(과거 리플레이) 사용으로 결정. 현재 방향은 [CONCEPT.md](CONCEPT.md) 참고. 아래 "라움 월드(가상 시장)"는 이후 확장 모드로 보류.

> 부모와 아이가 함께 **경제 뉴스·지표·차트를 읽고 → 예측하고 → 거래하고 → 결과를 되돌아보는** 게임형 투자 학습 시뮬레이션 앱

## 1. 개요

| 항목 | 내용 |
|---|---|
| 한 줄 소개 | 가상 경제 세계에서 주식·ETF·ETN·채권·원유·선물을 거래하며 "왜 가격이 움직이는지" 배우는 가족용 투자 게임 |
| 타깃 | 주 사용자: 초등 고학년~중학생(10~15세) / 공동 사용자: 부모 |
| 핵심 가치 | ① 돈 걱정 없는 실전 감각 ② 원인→결과(인과) 이해 ③ 부모-아이 대화 소재 |
| 플랫폼 | 모바일 앱(iOS/Android) 우선, 태블릿 대응 |
| 수익 모델(안) | 가족 구독(시나리오 팩·리포트), 학교/학원용 라이선스. **아동 대상 인앱 아이템 판매·광고는 하지 않음** |

### 학습 목표 (아이가 졸업할 때 할 수 있어야 하는 것)
1. 금리·물가·환율·유가가 각 자산 가격에 어떤 방향으로 영향을 주는지 설명할 수 있다.
2. 현물/ETF/ETN/채권/원자재/선물의 차이와 위험을 구분할 수 있다.
3. 뉴스 한 개를 보고 "누가 이득, 누가 손해"를 추론할 수 있다.
4. 분산투자·손절·레버리지 위험을 경험으로 이해한다.
5. 결과(운)와 판단(과정)을 구분해 회고할 수 있다.

## 2. 핵심 컨셉: "가상 나라 라움" 경제 시뮬레이션

실제 시장 데이터를 실시간으로 쓰면 ① 변동이 느리고 지루하며 ② 실제 종목 추천처럼 보일 수 있고 ③ 데이터 라이선스 비용이 큽니다. 그래서 **두 가지 모드**를 둡니다.

| 모드 | 설명 | 용도 |
|---|---|---|
| **라움 월드 (메인)** | 가상 나라·가상 기업·가상 뉴스. 시뮬레이션 엔진이 경제 상황과 가격을 생성 | 매일 플레이, 시즌 리그 |
| **역사 탐험 (시나리오)** | 실제 역사적 사건을 각색해 재현(2008 금융위기, 2020 팬데믹, 2022 급격한 금리 인상, 1970년대 오일쇼크 등). 날짜·이름은 처음에 가리고 끝나면 "사실 이건 ○○년이었어!" 공개 | 특정 개념 집중 학습 |

### 시간 구조: 턴제
- **1턴 = 가상 시간 1주** (설정에서 1일/1개월 선택 가능)
- 아이가 "다음 주로" 버튼을 눌러야 시간이 흐름 → 충분히 고민할 시간 확보, 실시간 중독성 배제
- 1시즌 = 52턴(가상 1년), 하루 플레이 권장량 3~5턴 (부모가 제한 설정)

## 3. 게임 루프

```
 ┌──────────────┐
 │ ① 브리핑 읽기 │  이번 주 뉴스 3~5개, 경제지표 변화, 시황 요약
 └──────┬───────┘
        ▼
 ┌──────────────┐
 │ ② 예측하기   │  "금리가 오르면 내 채권은?" 위/아래/모름 + 이유 한 줄
 └──────┬───────┘
        ▼
 ┌──────────────┐
 │ ③ 주문하기   │  매수/매도, 수량, (해금 시) 지정가·손절가
 └──────┬───────┘
        ▼
 ┌──────────────┐
 │ ④ 시간 진행  │  다음 턴 → 가격 변동 애니메이션
 └──────┬───────┘
        ▼
 ┌──────────────┐
 │ ⑤ 회고하기   │  예측 적중 여부 + "왜 그렇게 움직였을까" 해설 카드
 └──────┴───────┘ → 다시 ①
```

**핵심 원칙: 수익률보다 "판단 과정"에 점수를 준다.** 운 좋게 번 돈보다 근거 있는 예측에 더 큰 보상(→ 7장).

## 4. 거래 상품과 단계별 해금

처음부터 모든 상품을 열지 않고 **레벨에 따라 해금**합니다. 각 상품은 해금 시 짧은 튜토리얼(만화 3~4컷 + 퀴즈 2문제)을 통과해야 거래 가능.

| 단계 | 상품 | 아이용 비유 | 배우는 개념 | 가상 종목 예시 |
|---|---|---|---|---|
| Lv1 | **현물 주식** | 회사의 작은 조각을 사서 주인이 되는 것 | 매수/매도, 수익률, 배당, 실적 | 라움전자, 냠냠식품, 하늘항공, 초록에너지 |
| Lv2 | **ETF** | 여러 회사 주식을 담은 "과일 바구니" | 분산투자, 지수, 섹터, 운용보수 | 라움200, 반도체 바구니, 배당 바구니 |
| Lv3 | **채권** | 나라·회사에 돈을 빌려주고 이자 받는 약속 | 이자, 만기, **금리↑ → 채권가격↓**, 신용위험 | 라움 국채 3년/10년, 하늘항공 회사채 |
| Lv4 | **원자재(원유·금)** | 세상이 돌아가는 데 필요한 재료 | 수요·공급, 전쟁/날씨 이벤트, 안전자산 | 원유 ETF, 금 ETF |
| Lv5 | **ETN** | 증권사가 "이 지수만큼 돌려줄게" 하고 쓴 약속증서 | ETF와의 차이, **발행사 신용위험**, 괴리율 | 원유 ETN, 변동성 ETN |
| Lv6 | **선물** | "다음 달에 이 가격에 사고팔자"는 미래 약속 | 만기, 증거금, **레버리지**, 롱/숏, 강제청산 | 라움200 선물, 원유 선물 |
| 보너스 | 환율/해외자산 | 다른 나라 돈으로 바꿔 투자 | 환율 효과, 환헤지 | 달러 ETF, 이웃나라 지수 |

### 위험 상품 안전장치
- **ETN·선물**: 부모 승인 후 해금 / 전체 자산의 일정 비율(기본 20%) 이상 투자 불가
- **선물**: 레버리지 최대 3배로 제한, 증거금 부족 시 "마진콜" 경험 → 강제청산 연출 후 반드시 해설 카드 표시
- 레버리지 상품 수익이 크게 나도 배지·보상은 주지 않음 (도박성 강화 방지)

## 5. 정보 시스템 (판단 재료)

### 5.1 경제 지표 대시보드
| 지표 | 표시 방식 | 아이용 설명 |
|---|---|---|
| 기준금리 | 숫자 + 방향 화살표 | 돈을 빌리는 "가격" |
| 물가상승률(CPI) | 장바구니 아이콘 가격 변화 | 같은 돈으로 살 수 있는 게 줄어드는 정도 |
| 환율 | 라움화/달러 | 우리 돈의 해외 몸값 |
| 유가 | 드럼통 게이지 | 공장·비행기·자동차의 밥값 |
| 실업률 / 경기 지수 | 날씨 아이콘(맑음~폭풍) | 나라 경제의 "날씨" |

### 5.2 뉴스
- 매 턴 3~5개, **가상 신문 / 방송 / SNS** 형식 혼합
- 종류: 중앙은행 발표, 기업 실적, 신제품, 전쟁·자연재해, 정부 정책, 소문(가짜뉴스 포함)
- 뉴스마다 **신뢰도 배지**(공식 발표 / 언론 보도 / 소문) → "소문에 사고 뉴스에 판다", 가짜뉴스 판별 학습
- 고레벨에선 해설 없이 원문만 제공 → 스스로 해석하는 연습

### 5.3 시황 브리핑
- 마스코트 캐릭터(예: 부엉이 "라우미")가 지난 턴 시장을 3줄 요약
- "이번 주 가장 많이 오른/내린 종목과 이유"

### 5.4 차트
- 레벨 1: 선 차트만 / 레벨 3+: 캔들차트, 거래량 / 레벨 5+: 이동평균선, 비교 차트
- **뉴스 마커**: 차트 위에 "이 날 금리 인상 발표" 같은 핀 → 사건과 가격을 시각적으로 연결
- 비교 차트: 금리 vs 채권 가격, 유가 vs 항공주 등 관계 그래프 제공

### 5.5 "연결고리 지도" (핵심 학습 도구)
뉴스/지표가 어떤 자산에 영향을 주는지 보여주는 노드 그래프. 아이가 플레이하며 **스스로 화살표를 채워 넣는** 도감 형식.

```
금리 ↑ ──→ 채권가격 ↓, 은행주 ↑, 성장주(기술) ↓, 부동산 ↓
유가 ↑ ──→ 정유/에너지주 ↑, 항공·운송주 ↓, 물가 ↑
환율 ↑(라움화 약세) ──→ 수출기업 ↑, 수입 원자재 기업 ↓
경기 침체 ──→ 안전자산(국채·금) ↑, 소비재·여행 ↓
```

## 6. 시장 시뮬레이션 엔진

### 6.1 구조
```
[거시 상태]  금리, 물가, 성장률, 유가, 환율, 시장심리
     │  (턴마다 확률적 변화 + 시나리오 스크립트)
     ▼
[이벤트 생성기]  상태 변화 → 뉴스 텍스트 생성 / 무작위 이벤트(재해, 신제품, 스캔들)
     │
     ▼
[자산 가격 모델]  각 자산 = 팩터 민감도(베타) × 거시 변화 + 고유 이벤트 + 노이즈
     │
     ▼
[파생 계산]  ETF = 구성종목 가중합 / ETN = 지수 추종 ± 괴리 / 채권 = 금리·듀레이션 / 선물 = 현물 + 베이시스, 만기 수렴
```

### 6.2 가격 모델(초안)
```
수익률(자산 i, 턴 t) =
    Σ_k  β(i,k) × Δ팩터(k,t)        ← 금리, 유가, 경기, 환율, 심리
  + 이벤트 충격(i,t)                 ← 실적 발표, 뉴스
  + ε(i,t)                           ← 무작위 노이즈 (난이도로 크기 조절)
```
- 예: 하늘항공 β(유가) = −0.8, 초록에너지 β(금리) = −1.2, 라움 국채 10년 듀레이션 = 8
- **난이도 설정**: 쉬움 = 노이즈 작음(뉴스대로 움직임) / 어려움 = 노이즈 큼, 선반영("이미 가격에 반영됨"), 뉴스와 반대로 움직이는 경우 발생
- 엔진은 시드(seed) 기반 → 같은 시나리오를 가족이 같은 조건으로 대결 가능, 재현·디버깅 용이

### 6.3 시나리오 스크립트 예시 — "금리의 겨울"
| 턴 | 이벤트 | 기대 학습 |
|---|---|---|
| 1~4 | 물가 상승 뉴스 연속 | 물가↑ → 금리 인상 예상 |
| 5 | 중앙은행 금리 0.5%p 인상 | 채권↓, 기술주↓, 은행주↑ |
| 6~10 | 추가 인상 루머(소문 배지) | 소문의 신뢰도 판단 |
| 11 | 대형 기술기업 실적 쇼크 | 개별 위험 vs 분산투자 |
| 12~16 | 금리 동결 → 반등 | 바닥에서의 심리, 장기 투자 |

## 7. 보상·성장 시스템

### 7.1 점수 체계 (수익률 단독 평가 금지)
| 점수 | 비중 | 측정 |
|---|---|---|
| 🧠 판단력 | 40% | 예측에 이유를 적었는가, 예측 적중률, 연결고리 활용 |
| 🛡️ 위험관리 | 30% | 분산 정도, 최대 낙폭(MDD), 레버리지 사용 절제 |
| 📈 성과 | 20% | 시장 대비 초과수익 |
| 📝 성찰 | 10% | 투자일지 작성, 회고 퀴즈 |

### 7.2 진행 요소
- **레벨 & 상품 해금** (4장)
- **연결고리 도감**: 발견한 인과관계 수집
- **배지 예시**: "첫 배당금", "폭풍 속 분산투자자", "가짜뉴스 탐정", "금리 박사", "손절의 용기"
- **미션**: "이번 시즌 3개 이상 섹터에 분산하기", "금리 인상 전 채권 비중 줄이기"
- **가상 용돈 목표**: "라움 자전거 사기 (목표 자산 120만 라움)" 같은 목표 기반 저축·투자

## 8. 가족 기능

| 기능 | 설명 |
|---|---|
| **부모 대시보드** | 아이의 학습 진도, 자주 틀리는 개념, 위험 성향, 플레이 시간 |
| **오늘의 대화 카드** | 매 턴 회고 후 부모에게 질문 카드 제공. 예: "기름값이 오르면 우리 가족 생활에선 뭐가 달라질까?" |
| **가족 리그** | 같은 시드 시나리오로 부모 vs 아이 대결 → 결과 비교 리포트 |
| **예측 배틀** | 같은 뉴스를 보고 각자 예측 → 다음 턴에 공개 |
| **부모 설정** | 하루 턴 수 제한, 상품 해금 승인, 난이도, 알림 |
| **실생활 연결** | 주말 미션: "마트에서 가격 오른 물건 3개 찾기", "실제 뉴스에서 금리 기사 찾아오기" |

## 9. 학습 장치

- **용어 사전**: 화면 내 모든 금융 용어에 탭하면 아이 눈높이 설명 팝업
- **해설 카드**: 회고 단계에서 "왜 이렇게 움직였을까?" + 실제 세계 사례 한 줄
- **감정 체크**: 큰 손실/이익 후 "지금 기분은?" → FOMO·공포 매도 같은 투자 심리 학습
- **투자 일지**: 매수 이유를 한 줄로 적게 하고, 매도 때 다시 보여줌 ("처음 산 이유가 아직 유효해?")
- **실수 박물관**: 시즌 종료 후 가장 큰 손실 거래를 되짚어보는 리플레이

## 10. 화면 구성 (IA)

```
홈 ─┬─ 이번 주 브리핑 (뉴스·지표·라우미 요약)
    ├─ 시장 ─┬─ 상품 카테고리 탭 (주식/ETF/채권/원자재/ETN/선물)
    │        └─ 종목 상세 (차트·뉴스 마커·기업 정보·주문 버튼)
    ├─ 주문 (매수/매도·수량·지정가·손절가·예측 입력)
    ├─ 내 지갑 (포트폴리오 파이차트·수익률·위험 점수)
    ├─ 배우기 (튜토리얼·용어사전·연결고리 도감·퀴즈)
    ├─ 일지 (투자 일지·실수 박물관)
    └─ 가족 (리그·예측 배틀·대화 카드) / 부모 모드(PIN 잠금)
```

**주요 UX 원칙**
- 한 화면에 정보 과다 금지: 레벨이 낮을수록 숫자보다 아이콘·색·비유
- 상승=빨강/하락=파랑 (국내 관례) 유지 + 색약 대응 화살표 병기
- 큰 손실 시 과격한 연출 대신 차분한 해설로 전환

## 11. 안전·윤리·법적 고려

- **실제 돈 없음**: 실거래·실계좌 연동 없음. 가상 화폐 "라움"은 현금화·구매 불가
- **투자 권유 아님** 고지, 실존 기업·실존 종목 추천으로 오해될 표현 배제 (메인 모드는 전부 가상 기업)
- **아동 개인정보**: 만 14세 미만 가입 시 법정대리인(부모) 동의 필수(개인정보보호법), 해외 출시 시 COPPA/GDPR-K 대응. 최소 수집(닉네임, 생년, 부모 연락처)
- **사행성 방지**: 랜덤 박스·확률형 아이템 없음, 레버리지 보상 없음, 실시간 알림으로 재접속 유도 금지
- **콘텐츠 검수**: 뉴스 문구에 폭력·공포 과장 금지, 전쟁/재해 이벤트는 순화된 표현
- 역사 시나리오의 실제 데이터 사용 시 데이터 출처 라이선스 확인 (공공데이터: 한국은행 ECOS, 미국 FRED 등 우선 검토)

## 12. 기술 구조 (제안)

| 영역 | 제안 | 이유 |
|---|---|---|
| 앱 | React Native(Expo) + TypeScript | iOS/Android 동시, 웹 프로토타입 공유 쉬움 |
| 차트 | Victory Native / react-native-wagmi-charts | 캔들·라인 차트, 터치 인터랙션 |
| 시뮬레이션 엔진 | 순수 TypeScript 패키지 (시드 기반 결정적 난수) | 앱·서버·테스트에서 공용, 오프라인 플레이 가능 |
| 백엔드 | Supabase(Auth·Postgres) 또는 Firebase | 가족 계정, 리그, 진도 동기화 |
| 콘텐츠 | 시나리오·뉴스 템플릿을 JSON/YAML로 관리 | 기획자가 코드 없이 시나리오 추가 |
| 뉴스 문장 생성(선택) | 템플릿 기반 + LLM 보조 생성 후 사람 검수 | 다양성 확보, 아동 안전 검수 필수 |
