# 라움스톡 컨셉 v0.2 — "타임머신 투자 탐험"

> 결정 사항 (2026-11-23): **주 대상 초등학생**, **실제 데이터 사용**, **컨셉 프로토타입을 먼저 만들고 디벨롭**

## 한 문장 컨셉
아이가 타임머신을 타고 **'비밀의 해'**로 가서, 그해의 **진짜 뉴스와 진짜 가격**으로 1년을 투자해 보고, 끝나면 "사실 이건 2020년이었어!"를 알게 되는 게임.

## 왜 이 방식인가
| 고민 | 해결 |
|---|---|
| 실제 데이터를 쓰고 싶지만, 실시간 시장은 느리고 지루하다 | **과거 1년을 1주 = 1턴으로 빨리 감기** (53턴 ≈ 20~40분) |
| 실제 종목을 보여주면 '추천'처럼 보일 수 있다 | 이미 끝난 과거를 다시 보는 것 → 미래 추천이 아님. 화면마다 고지 |
| 아이는 결과를 알면 재미없다 | **연도를 숨김** ("비밀의 해 3월 2주"), 마지막에 공개 |
| 초등학생에게 지표·차트는 어렵다 | 공포지수 → "시장 기분 😊😟😱", 유가 → "석유 한 통 값", 차트 위 **뉴스 핀** |
| 수익률만 쫓으면 도박처럼 된다 | 점수는 **예측 + 이유**에서 나옴. 결과 화면은 "왜 그랬을까?" 해설 중심 |

## 초등학생용 조정 (기획서 v0.1 대비)
- 상품 해금: Lv1 주식 → Lv2 바구니(ETF) → Lv3 채권·금·원유. **ETN·선물은 잠금 상태로 '설명만'** (원유 선물 −37달러 사건을 뉴스로 체험)
- 금액: 씨앗돈 1,000만 원, 정수 주식만, 수수료 없음
- 문장: 한 문장 20자 내외, 비유 우선 ("바구니", "약속", "세상의 재료")
- 부모 카드: 매 턴 "부모님과 이야기해요" 질문 1개

## 첫 시나리오: 비밀의 해(2020)
2020년은 한 해 안에 **폭락(3월) → 금리 0% → 회복 → 사상 최고치 → 백신**까지 거의 모든 교과서 사건이 들어 있어 첫 시나리오로 가장 좋습니다.

| 시기 | 실제 사건 | 아이가 배우는 것 |
|---|---|---|
| 1~2월 | 우한 봉쇄, 크루즈선 격리 | 멀리서 시작된 뉴스가 내 종목에 오기까지 |
| 3월 | 폭락, 서킷브레이커, 연준 금리 0% | 공포, 분산투자, **금리↓ → 채권↑** |
| 4월 | 원유 선물 −37달러, 줌 사용자 20배 | 선물의 위험, 생활 변화가 만드는 승자 |
| 6~8월 | 일자리 깜짝 증가, 금 2,000달러, S&P 최고치 회복 | '예상과의 차이', 안전자산, 버티기 |
| 11월 | 화이자 백신 발표 | 같은 뉴스, 다른 결과 (크루즈↑ 줌↓) |

## 프로토타입 범위 (`prototype/`)
- 실제 주간 데이터 15종: 주식 7(줌·아마존·넷플릭스·애플·아메리칸항공·카니발·엑슨모빌), ETF 4(S&P500·나스닥100·한국·에너지), 채권 2(미국채 20년+·1~3년), 원자재 2(금·원유)
- 경제 날씨 4종: 시장 기분(VIX), 미국 기준금리, 10년 국채금리, 유가(WTI)
- 실제 뉴스 40개 (공식 발표 / 뉴스 배지)
- 턴 루프: 신문 → 차트(뉴스 핀) → 예측+이유 → 사고팔기 → 다음 주 → 결과·해설
- 레벨/점수, 해금 카드, 최종 공개 화면(성과·나눠 담기·생각하는 힘 별점, 배지 6종, S&P500 비교)
- 브라우저 저장(localStorage)으로 이어하기

실행: `prototype/index.html`을 정적 서버로 열기 (예: `cd prototype && python3 -m http.server`)
데이터 갱신: `node scripts/build-data.mjs`
